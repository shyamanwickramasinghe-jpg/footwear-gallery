📖 User Guide

Welcome to the DSI Footwear Operations portal. Use the tabs at the top to navigate. Here is how to use each section:

▶️ 1. Video Viewer (Motion Analysis)

  • Search & Select: Type an operation name to find it, then click to load the data.
  • Simulate Targets: Move the Performance and Allowance sliders. The Revised SMV and Hourly Target boxes will recalculate instantly.
  • Motion Study: Use the right-side video player to slow down the footage (0.25x to 0.75x) to analyze micro-movements.

📋 2. Operation Bulletin (Sharing)

  • AI Visual Scan: Upload a photo of a shoe to match local factory operations.
  • Web & YouTube Match: Upload a photo of unknown machinery to automatically generate clickable search links to similar tutorials worldwide.
  • Export & Print: Create your bulletin list, then download it as a lightweight CSV for software importing, or Print it directly to a clean PDF.

⚙️ 3. Manage (Admin Database)

  • Add New Operation: Enter the name, video link, draw a custom shape (optional), and add raw seconds.
  • Save Permanently: Once you add or delete operations, click the yellow Generate Code for GitHub button. Paste that code into your master file to save it for everyone.
